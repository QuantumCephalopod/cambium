# Self-Similar Systems — Living Display & Vascular Architecture Seed

## 0. North star

The public surface is not a website *about* Self-Similar Systems.

It is a perceptual organ of Self-Similar Systems.

The strongest recursive closure discovered so far is:

**the vascular network renders itself through its own vascular network.**

A metabolic event changes the organism; that change propagates through the same vascular machinery the site visualizes; the display rebuild is itself one consequence of that propagation; the visitor therefore encounters the organism through a membrane produced by the process they are observing.

---

# I. EARNED INVARIANTS

These should constrain implementation unless later metabolism genuinely supersedes them.

## 1. Recursive organism space

Every independently rooted organism begins from its own root.

Within one organism, semantic addressing recursively uses the invariant question grammar:

**w = CREATE · x = COPY · z = CONTROL · y = CULTIVATE**

A realized address may later differentiate again:

`x → xw / xx / xz / xy → ...`

There is no predetermined semantic depth.

### Wood

`INDEX.yaml` and address-local `_cambium.yaml` are **wood**.

They are not continuously changing runtime state.

They change only when actual cambial work earns a structural change: differentiation, regrowth, rebase, semantic correction, etc.

Ordinary metabolism may radically alter living tissue while leaving the wood byte-identical.

---

## 2. Occupancy is not descent

An organism living at `papers:x` does not thereby become `papers:xw`.

Host address and occupant identity remain separate.

Entering a nested organism crosses scope:

`papers:x ⟦ S.6arU:root ⟧`

The nested organism's internal address space begins again from its own root.

Filesystem nesting, spatial proximity and visual containment must never silently concatenate semantic addresses.

---

## 3. Three distinct recursive structures

The display must preserve the difference between:

### A. Semantic recursion

The host organism differentiates recursively through `w/x/z/y`.

### B. Organismic recursion

Every source organism already possesses its own tetrahedral relational body: 4 vertices, 6 edges, 4 faces, 1 volume and whatever metabolites/phenotype it has earned.

### C. Holonic recursion

Four same-rank organisms may birth a higher-rank organism:

`4 S → 1H`
`4 1H → 2H`
`4 2H → 3H`
`...`

These three structures rhyme tetrahedrally but must never be collapsed into one another.

# II. VASCULAR HYPOTHESIS

This is the major architecture currently being explored.

## 4. Every organic operation enters and returns through roots

Canonical pump gesture:

**ENTER → ACT → WITNESS → RETURN**

A pump first enters through the shared root receptor and then the organism-local receptor.

After its bounded work, it returns through the same rooted vascular hierarchy.

A pump should not need to know every downstream consumer of its work.

It should only need to produce a truthful bounded return.

---

## 5. `_feed` and `_roots`

Exact naming/location/schema remain provisional.

The emerging conceptual split is:

**`_feed` = pulse / causal return**

What happened here?

**`_roots` = current vascular orientation**

Which independently rooted wholes currently touch this whole, and what is their latest exposed boundary state?

A root never borrows the interior of another root.

It knows its boundary and how to reacquire that whole.

This role may eventually live close to `SKILLS`, because every organic operation necessarily crosses that receptor surface, but current folder conventions must not veto exploration of a better physiology.

# III. PROPAGATION

## 6. Local change propagates upward through semantic valves

Example:

`xyyxwz` changes.

The mechanical fact of change reaches its parent boundary.

At each parent there is a valve:

> Does this child's change alter what this parent currently means, exposes, depends upon, or must do?

If no, the pressure is absorbed locally.

If yes, the parent changes and emits its own return upward.

Therefore:

`xyyxwz → xyyxw → xyyx → xyy → xy → x`

is possible, but not mandatory.

Propagation follows earned consequence, not simple ancestry.

---

## 7. Pressure

A closed valve does not necessarily mean the event becomes irrelevant.

Repeated unresolved differences may accumulate as **pressure**.

Pressure is not automatically structural change.

But recurring pressure may eventually create a genuine cambial question:

> Does the current structure still adequately contain what repeatedly happens here?

Only if a new differentiation closes does pressure become wood.

This provides a plausible endogenous relation:

**metabolism → pressure → cambial differentiation → wood**

without splitting folders merely because they are busy.

---

## 8. Root reversal

When meaningful change reaches an organism root, its exposed boundary changes.

That can propagate upward until a larger/root vascular surface knows that one of its dependent roots changed.

Then direction reverses:

**UP → DOWN**

The upper root does not push semantic truth into descendants.

It sends reacquisition pressure:

> A dependency relevant to you changed. Re-enter it.

Affected organisms independently reacquire the changed boundary.

If their own living truth changes, they emit new returns:

**DOWN → UP**

The system therefore relaxes through repeated:

**UP → DOWN → UP → DOWN**

until no affected valve opens.

The settled state is vascular homeostasis.

---

## 9. Pathologies are real system states

This architecture naturally permits physiology-like failure modes without inventing decorative metaphors.

A blocked required return is an **occlusion**.

Repeated unresolved local change creates **pressure**.

Repeated reciprocal causal mutation without convergence is an **oscillation / arrhythmia**.

A stale required relation may create starvation-like loss of downstream freshness.

A successful causal loop closes as **circulation**.

Regeneration receives bounded wounds when continuity cannot close.

These states should eventually become directly perceptible.

# IV. DISPLAY

## 10. The display is a vascular participant

The display is not a passive database consumer.

A sufficiently meaningful upstream change produces pressure that eventually reaches a dependency relation involving display.

Display re-enters the exposed root state.

If its perceptual body must change, display changes and emits its own return.

A mechanical GitHub build/deployment can then be triggered as a consequence.

Therefore:

`papers metabolism`
→ `papers return`
→ `vascular propagation`
→ `display reacquisition`
→ `display mutation`
→ `GitHub build`
→ `public membrane`

The website visible afterward is literally a consequence of the vascular event.

The visitor needs to distinguish three fundamentally different motions.

The tetrahedral navigator remains continuous through arbitrary earned depth.

## 12. Cross root

`papers:x ⟦ S.6arU:root ⟧`

This crosses an organism membrane.

Crossing one of those parents crosses another root.

This creates whole-inside-whole navigation without identity collapse.

# VI. VISUAL SEMANTICS

## 14. WebGL / GPU space

The primary organismal field should be capable of becoming a true spatial, recursive, biological environment.

WebGL/WebGPU-class rendering is appropriate because we need potentially thousands of deterministic spatial elements, dynamic vascular flows, nested tetrahedral geometry, smooth scale transitions, shader-driven biological material and dense interaction without flattening everything into DOM cards.

The exact rendering library is not constitutional.

HTML/DOM can remain an accessibility, text and inspection membrane around the spatial organism.

## 16. Every visual degree must have an owner

**Position must encode data.**

No force-directed jitter or random scatter merely to avoid overlap.

If position exists, we must know what relation earns it.

Candidate spatial sources include semantic tetrahedral coordinates, earned phenotype coordinates, parent-derived holon geometry, address quotient geometry, or other explicitly defined relational quantities.

**Size must encode data.**

Candidate: metabolic mass / living body extent.

Raw file size is probably a poor measure because carrier encoding would masquerade as importance.

**Shape must encode data.**

Candidate: organism phenotype and internal tetrahedral structure.

An UNDERIVED phenotype should remain visibly unresolved rather than receiving invented morphology.

**Connections must encode real relations.**

Lineage, dependency, semantic adjacency and vascular circulation are distinct connection classes and should not be collapsed into one spaghetti graph.

**Motion must encode causal activity.**

Animation is strongest when something actually happened.

A pulse should move because a pulse occurred.

**Rhythm must encode actual pump cadence.**

**Pressure must encode accumulated unresolved consequential difference.**

No visual variable should silently acquire meaning just because it looks good.
