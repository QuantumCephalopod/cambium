# named places — current interaction refinement

## pressure

the first rendered trial exposed three usability problems: letter labels hid the
meaning already carried by the derived nouns; multiple public navigation modes
competed with the actual website; and the camera could turn only horizontally.
this note carries the live correction, not an archive of implementation steps.

## consequence

- one production navigator reads the recursively structured semantic organism in
  `INDEX.json`. runtime maps are derived views; the canonical index itself is not
  flattened into a node table.
- each breadcrumb label is the locally earned noun at its complete raw prefix,
  not a letter-to-name substitution. the URL retains the symbolic witness under it.
- the paired ancestry renderer is retained. geometric quotient may identify one
  place without erasing either raw genealogy; semantic coalescence is exposed only
  where independently realized witnesses carry the same semantic whole.
- living self-refinement remains a distinct raw address even when it occupies the
  same geometric point as its coarser witness.
- the names on the geometry are the same names used by the text navigator.
  root children appear in the same navigation landmark as current ancestry;
  unsplit leaves do not manufacture descendants or a second sibling menu.
- quaternion arcball rotation supports horizontal turning, vertical turning and
  rim roll. keyboard arrows, q/e and reset provide non-drag controls. camera
  state is independent from address and browser history. real drag gestures
  suppress link activation; taps and keyboard activation still enter places.
- label placement adjusts for readability and possible projection overlap only.
  it never changes a node's geometric or semantic identity.
- the named reciprocal fixture stays in renewal as test material, is not a route
  of the public site, and is not embedded into its generated data payload.

## existing anatomy remains sufficient

expression carries the revised template, typography, labelled view and camera
projection. continuity preserves the public wording with a bounded update to
orientation/renewal descriptions. orientation handles exact address identity,
route admission and selection. renewal carries the regenerated artifact and checks.
no second production split is warranted by this change, and none has been
materialized.

what changed is how the existing first split is carried as knowledge. the root's
current `whole` in `INDEX.json` is the metabolized rank-4 closure earned by its
4V/6E/4F/1T. the four child nouns and their current local wholes form the next
semantic resolution. the old detailed root derivation no longer functions as
canonical anatomy; it is retained in `_stomach/root-differentiation.md` as nutrient
whose remaining value has not yet earned another living distinction.

## witness scope

checks are rerunnable through build.py, check.py, test-address.cjs and
browser-check.py. synthetic fixture names test prefix sensitivity and recursive
address behavior; they are not independent production semantic derivations.
source geometry, actual first-level nodes and release boundaries remain unchanged.
no upstream merge, hosting, DNS, legal approval or public-contact choice is claimed.

## next review question

to learn the addressing grammar? further semantic depth must be earned by the
content, not added solely to make the interface look populated.
