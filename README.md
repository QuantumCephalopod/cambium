## try it

open `index.html` directly in a browser. it is a self-contained generated skin:
no CDN, remote font, framework, package install, analytics or application server
is needed. scripts only enhance the already-readable landing page. embedded
source JSON is a generated projection of the atlas and public contract.

one navigation surface shows the named places of the actual body. each breadcrumb
opens the complete prefix up to that noun. the geometry is the spatial expression
of the same atlas, not a second menu or a link to an addressing demonstration.

at the first split, the names are expression, continuity, orientation and renewal.
at a later realized split, every step will take its own local name from the index.
the paired trail remains available for genuinely realized reciprocal chambers;
`y/specimen.json` tests this with explicitly synthetic names without publishing
those extra branches. the original first-split receipt is unchanged; the current
interface correction is in [`y/interaction.md`](y/interaction.md).

drag the spatial view horizontally or vertically to rotate it. dragging around
the rim permits roll. with the map focused, arrow keys turn and tilt, q/e roll,
and home resets. the reset-view button restores the starting camera without
moving to another address. tab and enter also navigate all named places.

exact symbolic address keys and BigInt dyadic coordinates precede approximate
screen projection. only terminal self repetitions and the justified terminal
sibling junction are identified. arbitrary path reversal is not an address law.
URL fragments retain symbolic addresses; display names are not permanent IDs.

the public `study` namespace is retired. no fixture is shipped in the production
data block, and no unearned descendants have been added. the algebra remains
unbounded in definition; route parsing has an explicit 4,096-letter browser safety
budget. neither that budget nor viewport precision changes geometric identity.

## change and check

Python 3 and Node.js are development/test tools, not website runtime dependencies.
From this repository root:

```sh
python3 y/build.py
python3 y/check.py
node y/test-address.cjs
python3 y/build.py --check
```

on Windows, `py` can replace `python3`. edit the source limbs and atlas rather
than generated root `index.html` or `INDEX.md`.

Optional browser checks require Python Playwright and Chromium:

```sh
python3 y/browser-check.py --out ../cambium-review
```

The browser test injects the self-contained document into Chromium and checks
named navigation, free camera interaction, responsive layouts and an isolated
named-prefix fixture. Add `--http` to exercise a local server where browser policy
permits it. The injection run does not verify HTTP, file-open delivery, DNS or a
public deployment. Source-file existence is checked separately. Playwright uses a detected `chromium` executable or
its installed browser; `--chromium /path/to/browser` selects one explicitly.

For serving local source-file links as well as the generated skin:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

then visit `http://127.0.0.1:8000/`.
