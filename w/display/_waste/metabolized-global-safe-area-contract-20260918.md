# NUTRIENT — global Display safe-area contract

status: OPEN / UNRESOLVED
source: explicit user discussion after isolated Papers inspection
admitted_at: 2026-09-18
target: github.cambium...display
owner: Display root

## witnessed difference
Display owns persistent global membrane/status/navigation surfaces. Site-holons own their local phenomenology and presentation. Without one specimen-agnostic spatial contract between those layers, local site presentation can occupy the same screen region as persistent global Display surfaces. This is not Papers-specific; the collision class will recur for arbitrary current/future site-holons.

## unresolved pressure
Display needs a generic way to expose the screen region already occupied/reserved by global membrane UI and the remaining usable presentation area to every site-holon, so local presentation can inhabit the shared viewport without overlapping global state.

## boundary
- do not encode Papers-, Philosophy-, Crawlerbait- or future-site-specific layout rules in central Display;
- do not prescribe one site's local phenomenology, typography, HUD, inquiry behavior or content layout;
- do not treat a particular current pixel offset as the invariant;
- preserve global navigation/orientation ownership and site-holon local sovereignty.

## exit condition
A generic site-holon can receive/use one Display-owned safe-area / occupied-region contract such that persistent global membrane surfaces and local site presentation remain simultaneously legible without overlap across the accepted responsive viewport range, witnessed in the generated artifact with more than one site-holon and without central runtime branching on site identity.
