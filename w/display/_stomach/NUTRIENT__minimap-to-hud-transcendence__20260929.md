# NUTRIENT — minimap to HUD transcendence

status: OPEN / UNRESOLVED
source: Display invariant pressure

target: display

## encounter

The global minimap currently exists as an overlay-oriented navigation surface. Pressure emerged that this invariant should mature from an external overlay into an integrated HUD membrane.

## distinction

The minimap is not merely a map widget. It expresses global orientation, population awareness and relation to the current Display field.

Transcending overlay → HUD means preserving the invariant while changing embodiment:

old:

separate visual layer displaying orientation information

new:

persistent navigational organ integrated into the witness interface.

## constraints

- global orientation remains Display-owned;
- site-holons remain sovereign over their local phenomenology;
- HUD must remain specimen-agnostic;
- navigation identity and address-space truth continue to come from Population anatomy.

## unresolved

- Which HUD embodiment preserves the tetrahedral orientation relation best?
- How does the HUD coexist with site-local manifestations?
- What parts are global invariant and what parts are visual implementation?

This nutrient requests exploration only and does not authorize immediate UI mutation.
