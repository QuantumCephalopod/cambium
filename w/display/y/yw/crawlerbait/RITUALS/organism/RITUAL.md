## static sensor membrane

Crawler requests remain ordinary static CDN/Pages traffic. No crawler read invokes a Worker merely to announce presence.

Cloudflare is a passive observation provider. Provider telemetry is evidence of HTTP contact, not authenticated actor identity or intent.

The current sensor domain is **all 404 groups returned by Cloudflare for each queried window**, grouped by requested path and User-Agent. Within that domain there is deliberately no relevance filter, recurrence threshold, ranking, candidate shortlist, route budget, total-route cap, or signature cap. One observed group is already an observation and therefore belongs to Continuity.

The requested path and User-Agent string are retained as returned by the current sensor. User-Agent is always labelled as a client claim; it is spoofable. The current sensor does not request client IP addresses.

## Boundary is not a relevance filter

`z · Boundary` may constrain **representation**, never erase observation.

If an observed HTTP path can be emitted exactly as a static Pages path without escaping the artifact or colliding with Display-owned/public control namespaces, Sediment grows at that exact path. If the substrate cannot safely represent that address (for example a reserved namespace, dot-path, traversal-like path, control character, or filesystem-incompatible component), the observation still remains complete in Continuity and receives a deterministic archival receipt under `/crawlerbait/bait/<path-hash>/`.

Thus:

`observation retained ≠ exact static address necessarily representable`

but never:

`unrepresentable ⇒ observation discarded`.

## tide

One ordinary tide is:

`Cloudflare 404 groups → x Continuity → z representation boundary → w Sediment`

All returned positive-count groups are accumulated. No-change tides leave organism bytes unchanged. Provider query/window limits are transport constraints, not ecological selection.

### retained-history reseed

A manual `full_history=true` run rebuilds Continuity from the complete history currently retained by Cloudflare. It asks Cloudflare for the live dataset limits, partitions the retained interval into provider-sized windows, starts from empty local Continuity, and assimilates every returned 404 group from every window.

This is an explicit reseed, not a once-only migration. It may be rerun deliberately when the observation law itself changes. The final state advances its continuity cursor to the end of the fully queried retained interval, after which ordinary periodic tides resume from that cursor.

## public route law

Crawlerbait-local HTTP routes such as `/login` or `/admin` are not global Display addresses and are not CCCC vertices. They are outward apertures generated by `w · Sediment` from observed local state.

The public reef is deliberately crawlable and ordinary. Human-facing Display may visualize the same state as tracks, crabpots, fossils, moiré or Sierpiński-like fields, but that phenomenology remains identity-owned and must not leak into central Display semantics.

9. whole-body remounting changes only global address, never internal bytes;
