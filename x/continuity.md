# continuity — display inheritance interface

**host address:** `x / continuity`

Cambium's continuity limb remains real even though visitor-visible content belongs to
the `display` organ.

The current visible wording is carried inside `w/display/content.json`. Host `x` does
not duplicate those bytes. Its living role is to preserve the inheritance relation by
which public identity, accepted distinctions and provenance remain traceable while the
display changes presentation, carrier or internal structure.

## boundary contract

- display owns and metabolizes visitor-facing content;
- host continuity witnesses whether a display change preserves, deliberately revises,
  or breaks the public meaning inherited by the surrounding cambium organism;
- a purely presentational display change need not become new host continuity tissue;
- a change that alters what cambium publicly carries is a continuity event and must
  revalidate the affected host closure/dependency cone;
- `x / continuity` is a host role, not `display:x` and not a duplicate content store.

This file is therefore an interface/continuity carrier for the host limb itself. It
keeps the relation explicit while allowing display to remain the sole owner of the
visitor-facing content body.
